# Scripts em R para análise de dados e estatística em pesquisa e desenvolvimento

Este repositório reúne uma coleção de scripts em R criados para apoiar projetos de pesquisa e desenvolvimento em qualidade pós-colheita, análise de armazenamento, avaliação de condições ambientais e interpretação de dados experimentais.

## Finalidade

Os scripts têm como objetivo principal:

- Organizar e processar dados de testes laboratoriais e de campo;
- Realizar análises estatísticas para comparar tratamentos, lotes, posições e condições experimentais;
- Modelar respostas relacionadas a qualidade do produto, como acidez, sólidos solúveis, condensação, temperatura e umidade;
- Gerar gráficos e relatórios visuais para facilitar a interpretação dos resultados;
- Apoiar decisões técnicas em projetos ligados a armazenamento, embalagem, logística e avaliação de perdas.

## Tipos de análise presentes

Os arquivos aqui contidos incluem rotinas para:

- Testes estatísticos com modelos logísticos, ANOVA e comparações múltiplas;
- Transformação e limpeza de dados;
- Visualização de tendências temporais e variações ambientais.

## Observação

Os scripts são majoritariamente scripts analíticos e experimentais, desenvolvidos para uso específico de cada projeto, sendo úteis como base para estudos, automação de relatórios e reuso em análises de dados semelhantes.
